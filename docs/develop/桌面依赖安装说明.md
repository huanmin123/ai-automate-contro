# 桌面依赖安装说明

## 当前结论

桌面线已移除 OCR。运行时不再需要 Tesseract、pytesseract、`tessdata.eng` 或 `tessdata.chi_sim`，`desktop-env`、`desktop-components` 和 release matrix 也不再提供 OCR 强制门禁。

不要为了桌面自动化安装或配置 OCR 依赖；`config.json` 中的 `desktop.ocr` 会校验失败。

## Python 依赖

安装桌面可选依赖：

```powershell
python -m pip install -e ".[desktop]"
```

关键能力：

| 能力 | 依赖 | 用途 | 能力矩阵字段 |
| --- | --- | --- | --- |
| 截图 | Pillow / ImageGrab | `desktop_capture`、标注、视觉 source | `dependencies.Pillow.ImageGrab` |
| 图像模板定位 | OpenCV | `desktop_vision type=locate_image` | `dependencies.opencv-python` |
| 系统输入 | pyautogui | `desktop_input` 键鼠 | `dependencies.pyautogui` |
| 剪贴板输入 | pyperclip | `desktop_input type_text method=clipboard` | `dependencies.pyperclip` |

`pyproject.toml` 中的 `desktop` extra 还声明了 `mss` 和 Windows `pywinauto`。它们属于桌面增强依赖：当前能力矩阵不把它们作为必需项，后续截图后端、UIA backend 增强或问题定位时可以继续使用。

## Windows

推荐在 PowerShell 7 中运行：

```powershell
python .\cplan.py self-check desktop-env --require-input --require-vision
python .\cplan.py self-check desktop-components --require-input --require-vision
```

Windows 桌面真实 App 回归：

```powershell
python .\cplan.py self-check desktop-real-app
```

## macOS

安装依赖后运行：

```powershell
python3 cplan.py self-check desktop-env --require-input --require-vision
python3 cplan.py self-check desktop-components --require-vision
```

macOS 权限：

- Accessibility：控件树、窗口操作和系统输入通常需要。
- Screen Recording：截图和视觉定位通常需要。
- Automation：部分 App 控制可能需要。

授权必须由用户在系统设置中完成。代码只能触发提示、打开设置或等待人工确认。

## 验证命令

基础诊断：

```powershell
python .\cplan.py self-check desktop-env
```

组件回归：

```powershell
python .\cplan.py self-check desktop-components
```

发布前桌面门禁：

```powershell
python .\cplan.py self-check release-matrix --strict-desktop --fail-fast --step-timeout-seconds 1200
```

`--strict-desktop` 只强制桌面输入、视觉和桌面组件，不包含 OCR。
