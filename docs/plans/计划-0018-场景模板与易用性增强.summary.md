# 计划-0018 摘要

本轮目标是把现有 action 能力沉淀成可复用场景模板，降低用户从自然语言需求到可运行 plan 的成本：

- 新增 plan 模板目录与 `cplan create --template <id>` 创建入口，模板仍生成普通 plan 包，不新增 DSL。
- 支持 `cplan create --param key=value` 和 AI 工具 `template_params` 覆盖模板变量，未知参数或类型错误直接失败。
- 当前落地 `browser-login-extract`、`excel-cleaning-report`、`api-to-excel`、`browser-download-process`、`sql-import-export`、`desktop-file-dialog-batch` 六个模板。
- AI 终端按模板补充问答式槽位收集、执行线确认、风险确认和模板化 plan 生成规则。
- 新增模板 cookbook 和模板回归入口，确保模板可校验、可运行、文档可追踪；`api-to-excel` 在自检中启动本地 API 服务端到端验证。
- 继续遵守当前 schema 和 action 契约，不为旧字段或旧命令增加兼容分支。
